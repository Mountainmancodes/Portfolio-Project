# Mountainmancodes Portfolio Website

## Project Description

This portfolio website showcases my skills, experiences, and projects as a software engineer and mountain enthusiast. Initially created as a representation of learned knowledge from the CSS unit, it has now evolved into a dynamic React-based application.

## Features

### React-based Single Page Application

- Utilizes React for a smooth, dynamic user experience
- State management for seamless content transitions

### Responsive Design

- Adapts to various screen sizes for optimal viewing on desktop and mobile devices

### Interactive Components

- Navigation tabs for easy access to different sections (Experience, Projects, Education, Contact)
- Skills section with categorized display of technical competencies

### Modern UI/UX

- Clean, minimalist design focusing on content and usability
- Consistent styling with CSS variables for easy theme customization

## Technologies Used

- React.js
- HTML5
- CSS3
- JavaScript (ES6+)

## Getting Started

To run this project locally:

1. Clone the repository

   ```
   git clone https://github.com/mountainmancodes/portfolio-website.git
   ```

2. Navigate to the project directory

   ```
   cd portfolio-website
   ```

3. Install dependencies

   ```
   npm install
   ```

4. Start the development server

   ```
   npm start
   ```

5. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Build

To build the app for production:

```
npm run build
```

This builds the app for production to the `build` folder.
